## 🌟 Overview
**CariKampus** adalah platform mobile inovatif yang mengintegrasikan data pendidikan tinggi global ke dalam satu antarmuka yang intuitif. Dikembangkan menggunakan **Flutter**, aplikasi ini memungkinkan pengguna untuk mengeksplorasi ribuan universitas, melakukan perbandingan mendalam, dan mengelola database catatan kampus secara personal.

## ✨ Fitur Unggulan

- **🔍 Discovery Engine**: Pencarian cerdas berbasis API Hipolabs yang mencakup seluruh perguruan tinggi di Indonesia.
- **🛡️ Automatic Branding**: Deteksi logo instansi secara dinamis menggunakan domain web resmi via Google Favicon Service.
- **📊 Comparison Mode**: Fitur perbandingan *side-by-side* untuk membantu pengambilan keputusan akademis.
- **💾 Persistent Storage (SQLite v5)**: Manajemen data lokal dengan fitur CRUD lengkap:
  - **Create**: Bookmark kampus favorit.
  - **Update**: Tambahkan catatan personal (catatan pendaftaran, jurusan, dll).
  - **Delete with UNDO**: Sistem keamanan penghapusan data dengan konfirmasi SnackBar.
- **🧭 Premium Navigation**: Sistem navigasi yang mematuhi rubrik akademik dengan tombol **Back** dan **Home** di setiap layar.

## 🛠️ Technical Stack
- **Framework**: Flutter SDK
- **Database**: SQLite (sqflite) with Version 5 Migration
- **Networking**: REST API Integration (Asynchronous HTTP)
- **UI/UX**: Custom Indigo Theme, Material Design 3, Google Fonts (Poppins)

## 🎯 Rubric Compliance
- [x] **Splash Screen**: Responsif dengan durasi 3 detik & branding institusi.
- [x] **State Management**: Pengelolaan state navigasi dan filter yang dinamis.
- [x] **Database Operations**: Full CRUD (Create, Read, Update, Delete) pada SQLite.
- [x] **API Connectivity**: Integrasi real-time data dengan error handling (Retry Mechanism).
